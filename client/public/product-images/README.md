# صور المنتجات

ضع صور التطبيقات والألعاب والمنتجات هنا. لا تحتاج لتعديل الكود: الفهرس يُبنى تلقائيًا قبل كل `pnpm build`، ويمكنك تشغيله يدويًا بـ `pnpm images:index`.

## التسمية

| نوع التسمية | مثال | ماذا يطابق |
|---|---|---|
| اسم المنتج | `free-fire.webp` | منتج اسمه «Free Fire» أو «فري فاير» |
| معرّف المورد | `id-12345.png` | المنتج ذو المعرّف `12345` لدى Fast4Top |
| مجلد القسم | `games/free-fire.webp` | نفس الاسم مع ترجيح قسم الألعاب |
| اسم عربي | `ببجي.png` | منتج «ببجي» أو «PUBG» |

- الفواصل (`-` أو `_` أو مسافة) كلها مقبولة، والحروف العربية تُطبَّع تلقائيًا (أ/إ/آ ← ا، ة ← ه، ى ← ي).
- المطابقة تتجاهل الكلمات العامة مثل «شحن» و«رصيد» حتى لا تختلط الصور بين المنتجات.
- عند وجود أكثر من مطابقة، يفوز الاسم الأكثر تطابقًا، ثم الصورة داخل مجلد القسم الصحيح.

## الصيغ والمقاسات

- الصيغ: `png`، `jpg`، `jpeg`، `webp`، `avif`، `svg`.
- شعارات التطبيقات والألعاب: مربّعة `512×512` بخلفية شفافة، وستظهر كاملة داخل البطاقة.
- صور الأجهزة والإكسسوارات: `1200×900` تقريبًا، وستُقصّ لملء البطاقة.
- استخدم `webp` إن أمكن لتقليل الحجم، وتأكد أن اسم الملف يطابق اسم المنتج حرفيًا أو معرّفه.

## أولوية العرض

1. صورة رفعها المالك من لوحة الإدارة (أو صورة المورد).
2. صورة محلية مطابقة في هذا المجلد.
3. شعار علامة احتياطي من الشبكة (إن وُجد).
4. بلاطة بديلة مولّدة بالكود تحمل الحرف/الكلمة الأولى من اسم المنتج مع لون ثابت — تظهر بدل الصورة المكسورة أو الفارغة.

## بعد إضافة الصور

```bash
pnpm images:index   # اختياري: يبني الفهرس فورًا
pnpm build          # يبني الفهرس تلقائيًا ثم يبني الموقع
```

لا تضع هنا صورًا بحقوق لا تملكها. الشعارات الرسمية للتطبيقات والألعاب مسؤولية المالك.
